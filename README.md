# Voice Command Recognition

## Description

A Python-based voice command system that recognizes spoken commands and provides appropriate responses.

## Commands

- Hello
- Time
- Search
- Help
- Exit

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Google Speech Recognition

## How It Works

1. The microphone captures the user's voice.
2. Speech recognition converts the voice into text.
3. The recognized text is compared with predefined commands.
4. The appropriate response is displayed.
